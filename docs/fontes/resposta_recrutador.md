# Atualização do recrutador sobre MCP e Skill

- **Origem:** mensagem fornecida por Robson durante a entrevista do PRD
- **Registrado em:** 2026-09-21
- **Autoridade:** esclarecimento posterior e específico; prevalece sobre o trecho antigo da página pública que exigia API.

> Fala Robson! A prova técnica precisou ser atualizada pra deixar mais claro o que a gente quer ver. No lugar da API, entram duas coisas: um MCP em cima das regras dos convênios e das guias (consultar regra e verificar guia), e uma Skill pra quem opera a clínica conferir uma guia colando os dados como a recepção escreveu.
>
> O link é o mesmo e a página já está com a versão nova. Se você já tinha começado, sem problema nenhum: o que já foi feito continua valendo, inclusive se foi pela API. O resto da prova não mudou.

## Interpretação para o PRD

1. O MCP é obrigatório e deve, no mínimo, consultar regra e verificar guia.
2. A Skill é obrigatória e deve permitir que a operação confira uma guia colando os dados como foram escritos pela recepção.
3. A API deixou de ser um entregável obrigatório.
4. Uma API já feita ou escolhida como superfície adicional continua válida, mas não substitui MCP e Skill.
5. Os demais requisitos da prova permanecem inalterados.
